## Agent skills

### Issue tracker

Issues dicatat di GitHub Issues (`jojoevan/kka-project-group-8`) dan dikelola lewat CLI `gh`. See `docs/agents/issue-tracker.md`.

Memakai lima label bawaan: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

Single-context: `GLOSSARY.md` dan `docs/adr/` di root repo. See `docs/agents/domain.md`.
